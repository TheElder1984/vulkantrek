# EGATrek reference and intentional departures

Exact DOS parity is no longer the product target. VulkanTrek is an original
command strategy game inspired by EGATrek. Its release criterion is a complete,
understandable and playable mission, specified in [RULES.md](RULES.md).

The earlier comparison work remains available in
[REFERENCE_OBSERVATIONS.md](REFERENCE_OBSERVATIONS.md) and the original starting
state fixture. Five-rank observations supported the chosen 5000 main energy,
2500 shields, warp 1 and stardate 3500 defaults. They do not prove combat parity.

The author’s EGATREK.DOC and EGATREK.REF in the
[EGATrek 3.1 archive](https://www.dosgamesarchive.com/file/egatrek/egatrk31) informed
the command vocabulary. The original was also run under DOSBox; private reference
files are ignored under `.reference/egatrek31/` and excluded from game exports.

Intentional departures now include shared main power for movement and lasers,
command-only enemy responses, automatic local routing, live fleet intelligence,
a finite rank-scaled fleet, a mission deadline, defined class behaviors, one
optional relief event and our own scoring. The original impulse bank is not
needed by this ruleset. Original event formulas, Vandal encounters, black holes,
rare phenomena, promotions and historical prompt fidelity are not release blockers.

The procedural geometry, cinematic camera, mouse controls, sound and shaders are
original presentation. No original executable, text or graphics are redistributed.
